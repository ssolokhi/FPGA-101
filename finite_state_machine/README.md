# Finite State Machine

A *finite state machine* (FSM) is a collection of states and transitions between them that are triggered by certain actions/inputs.

This example uses a FSM to create a simple game with the following rules: first, a random bit sequence is generated by a 
*linear feedback shift register*. This sequence is displayed by 2 LEDs (this limitation is due to the resources available on my beginner FPGA board). 
The user has to use 2 buttons to replicate this sequence. The input sequence will be compared to the generated one. 
If they match, the user gets one point. If they do not match, the game is reset.

The score is displayed with a 7-segment display, which is located on an external breadboard and driven by multiple I/O ports on the FPGA. 
The segment order is taken and can be found in e.g. [this tutorial](https://www.electronics-tutorials.ws/blog/7-segment-display-tutorial.html).
